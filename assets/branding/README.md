# MeshScout branding assets

meshscout-logo.jpg is the original user-supplied IMG_6451.JPG, preserved unchanged. meshscout-shield.png was extracted from that artwork with the built-in image generation tool for the Android icon foreground. Extraction prompt: Extract only the original glowing cyan eye/shield emblem above the MESH SCOUT lettering; remove lettering and carbon background; preserve the original silhouette, metallic details, cyan eye and hexagonal mesh, without redesign or added elements; center on transparency.

Android density assets are resized derivatives. The 60 dp foreground fits inside the adaptive icon safe region. Android 12+ uses the shield for the system splash, followed by the full-artwork Flutter startup screen. Earlier Android versions also display the full artwork in the native launch background. Device appearance remains subject to launcher masks and screen size; physical acceptance is required.
